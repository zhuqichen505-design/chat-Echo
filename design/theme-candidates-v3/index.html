显示

瓷光

PORCELAIN

轻釉般的清透表面。细投影托起内容，蓝色只出现在值得注意的地方。

精确、安静、有触感。弧面按钮 / 浅釉分区 / 浮起一毫米的选中态

字场

TYPEFIELD

文字自己构成界面。日期目录、鲜明字级和横线节奏，朱红是一枚标点。

像一份每天翻开的好刊物。编辑网格 / 通栏日期目录 / 文字即导航

映夜

AFTERIMAGE

故事有自己的银幕。宽幅场景、字幕式阅读与微弱边光，把长对话留给夜晚。

沉浸，从第一眼开始。自绘电影场景 / 宽幅继续入口 / 字幕式消息

织页

COMMONPLACE

随手记，也认真写。可翻动的标签、细密页线和一处压印，让每段想法有归处。

文具的亲近感，工具的清楚。页边标签 / 横格节奏 / 纸夹与压印细节

游园

BOTANICA

一条留给想法的小径。植物线描、拱形构图和清晰列表，在秩序里留一点生机。

自然，不等于随意。原创枝叶线描 / 拱形叙事入口 / 深绿与一点酸橙

所有会话、统计与人物均为合成内容。搜索、筛选、导航、折叠、开关、输入、动画状态都可操作。输入只展示在本地，不保存、不发送。插图均由 SVG 自绘。

推荐模式：映夜使用深色，其他使用浅色；可统一切换浅深和纯白/纯黑。网页字体来自本机；Android 上的实际字体、触控与尺寸需要单独适配验收。
