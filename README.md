## 功能

- 多 API 配置、模型切换、流式回复、思考与高级参数。
- 回复方向选择、消息编辑与重新生成、后台生成。
- 角色卡、世界观、故事时间线与待确认增量提取。
- 智能记忆、上下文预算、摘要与主动压缩。
- 联网搜索、图片与附件输入、OCR 辅助。
- 对话文件夹、历史记录、使用统计、个性化与备份恢复。
- 聚焦对话与侧栏工作台两种首页布局，共享会话、创作、统计、设置四个入口。
- 晴空、夜航、索引主题，以及独立的创作阅读样式与流式动画设置。

提取结果需要模型遵守格式指令，并由用户确认后保存；不保证所有服务兼容或每次提取成功。HTTP 默认关闭，白名单仅本机保存；HTTP 不加密消息和凭据，优先使用 HTTPS。

## v2.8.4：首页、外观与创作

在“设置 → 界面与外观”选择**聚焦对话（底栏）**或**侧栏工作台（左栏）**。聚焦对话优先展示新对话与最近会话；工作台突出继续故事与创作资料。两种布局使用相同的会话、创作、统计、设置入口，保留搜索、文件夹、历史、置顶、多选及会话管理操作。列表紧凑模式和“显示继续故事”开关对两种布局都生效；隐藏或私密故事不会出现在普通首页推荐中。

配色、首页布局、阅读排版和动画独立保存。主题可选晴空、夜航、索引，旧用户默认保留经典配色，浅色/深色/跟随系统仍单独选择。创作正文可选沉浸叙事、简洁正文或分栏上下文；分栏显示已保存的故事资料，宽屏并排、窄屏折叠，继续支持 Markdown 与消息操作。流式动画可选细光标、微声波或墨环，系统关闭动画时显示静态指示。

首页方案 01/02 已落地；创作书架、索引仪表盘、时间线叙事和一页任务仍是设计预览，不是应用内选项。详情见 [设计研究](design/roleplay-rework/research.md)、[主题与阅读交互样稿](design/roleplay-rework/comparison.html)和[首页布局方案](design/roleplay-rework/layout-options.html)。HTML 与截图均为合成内容，不代表 Android 设备验收。

## 世界书与聊天修复

世界书 JSON 可从角色与创作页顶部或设置中的世界书区域导入。支持 SillyTavern 对象、Character Book 数组及角色卡内嵌世界书的基础内容。导入前展示兼容提示，保存为**默认关闭的独立副本**，不覆盖同名资料，也不自动绑定故事。先在世界书列表检查并启用书目及词条，再到对话/故事设置高级区打开世界书并选择书目。

书目可选“全部已启用”或“仅选中”；“仅选中”且未选任何书时不会发送世界书。词条按本轮输入和压缩前最近 4 条有效消息原文触发，旧回复变体与排除消息不参与，旧置顶不会冒充近期消息。常驻词条直接参与；统一受 1500 个估算 token 预算限制，过大条目跳过。预算保留优先级不代表模型指令权限。

高级正则、宏、位置/深度、概率及未知扩展尚未完整兼容；预检会说明损失，相关条目默认停用，原始扩展不会保存。角色卡导入仅提取世界书部分，不导入角色本体。当前不承诺无损导出或与外部客户端完全相同的行为。

创作提示保留用户全局规则与故事要求，去掉每张人物卡重复的固定文风铁律；没有记忆条目时仍携带已保存的当前故事时间。重新生成恢复原附件与 MIME 信息，故事设置串行保存后再读取发送。流式回复结束落库保持列表身份和当前阅读位置，重新进入生成中的会话可继续看到活动回复。

v2.8.4 的编译、单测与 Lint 联合验证退出 0：84 套件 / 643 项测试全部通过，失败、错误、跳过均为 0；Lint 0 Error / 88 Warning，差异检查退出 0。安装包与发布核验结果见 [最新发布说明](release-notes/latest.md)；设备安装、启动、输入法及真实接口仍需验收。

## 隐私与上传要求

每次提交、推送或上传附件前，**必须核查并确保内容不含任何用户个人信息或隐私**。覆盖完整文件、待上传历史与元数据、图片及附件；发现疑点立即停止上传。真实凭据、私人接口、本机用户名路径、聊天记录与备份不得进入仓库。

示例使用合成数据、文档保留地址或 `.test` / `.invalid` 域名。配置和真实地址仅在自己的设备填写。应用会将请求内容发送至所选模型或搜索服务，本地存储不意味着数据从不离开设备。

历史对象与平台缓存不因新提交自动消失；已发现的历史隐私残留尚需单独处理，不宣称已彻底清除。维护执行清单见 [WORKFLOW_GUIDELINES.md](WORKFLOW_GUIDELINES.md)。

## 从源码运行

需要 JDK 17、Android SDK 34；版本依赖以 Gradle 配置为准。将本机 SDK 路径放入未跟踪的 `local.properties`，不要提交本机配置或签名文件。

```powershell
./gradlew.bat compileDebugKotlin --no-daemon
./gradlew.bat testDebugUnitTest --no-daemon
./gradlew.bat lintDebug --no-daemon
```

源码公开用于正常开发与审查；不再展示旧版本发布列表。数据库为 Room v34（20 个实体），升级禁止破坏性迁移。构建配置可能包含本机 JDK 指向，请在自己的环境使用有效 JDK 17。
