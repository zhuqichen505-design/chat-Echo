# Echo 2.8.31

版本 2.8.31/217，Room v37（20 个实体）不变。

## 输入框

- 修复打字时偶现“输入的字没有出现在输入框”和输入法闪一下：点击输入框现在会同时判断输入连接是否仍然可用，不再只看窗口 Insets。
- 悬浮输入法、或输入法只是被收起但连接仍在时，只重新显示键盘，不再清空焦点重建，避免收起再弹起的闪动与正在合成的文字丢失。
- 输入连接确实失效，或确认输入法显示后被收起（例如按返回键）时，才重建输入会话。
- 恢复草稿时光标落在文字末尾，输入从末尾继续。

## 发送与滚动

- 新增“设置 → 界面与外观 → 对话滚动 → 发送消息后自动滑到底部”，默认开启。
- 开启：发送后自动跟随到最新消息，覆盖消息落库、等待气泡插入与键盘收起动画的时间差；手指拖动列表会立即让出。
- 关闭：发送后保持当前阅读位置，本轮流式回复也不会把页面抢回底部；手动滚回底部后恢复跟随。
- 编辑消息重发仍定位到被编辑消息，不受该开关影响。

## API 配置

- 新建 / 编辑 API 配置页沿用设置页的壁纸、纸纹与悬浮玻璃顶栏，不再像“放大的弹窗”。
- 连接、密钥、模型三个页签按功能分组为玻璃卡片，卡片标题、间距、圆角统一；页签分隔线不再是生硬的横线。
- 密钥卡片改为两行：第一行拖拽手柄、Key 标签、备注、启用开关、上下移与删除，第二行是全宽密钥输入框；窄屏下备注和密钥不再互相挤压，上下移按钮保留。
- 内层 Key 卡片、搜索框、密钥输入框与添加按钮的圆角统一为 12dp。
