# 当前版本说明

## Echo 2.9.6/241（2026-11-27）

- **长期记忆架构全面升级（M1 核心引擎 · 无需额外模型）**：
  - **中文分词与混合检索引擎**：修复旧版按空格切分导致中文记忆检索失效的问题，取消数据库 `LIMIT 80` 截断；引入统一中英 2/3-gram + BM25 + 实体权重 + 分类衰减 + ACT-R 访问热度 + 1-hop 关联扩散 + MMR 多样性去重排序。记忆总预算随模型上下文窗口动态放大（大窗口最高至 8,000 tokens），消除静态指令超预算崩溃隐患。
  - **分类体系、冲突软归档与写入模式解耦**：`memory_items` 新增分类（`IDENTITY / VOICE / INSTRUCTION / PREFERENCE / PROJECT / FACT`）、重要度（1–5）、置顶常驻（`isPinned`）及冲突演化软归档（`archivedAt / supersededById`）；旧版 `global` 自动归一为 `user` 并回填分类与重要度。新增本地门控过滤器拦截闲聊与一次性任务，SmartAdd 结构化 JSON 仲裁支持 `ADD / MERGE / CONFLICT / SKIP`，冲突覆盖自动软归档留存且可在设置页一键恢复；支持「自动静默写入」与「手动审核」双模式切换。
- **可选语义向量检索（M2 Embedding · 默认关闭，无嵌入模型零影响）**：
  - 支持在设置 →「提示词与记忆」中按需开启并独立绑定 OpenAI 兼容 `/embeddings` 接口与模型名；开启后使用 RRF ($k=60$) 融合语义向量与 BM25 检索，内置 `embeddingSpaceId` 空间隔离防混维、Token 感知分批索引与短超时保护；关闭、未配置或接口异常时 100% 自动回退至 M1 全流程，不阻塞聊天。
- **设定/时间线防遗忘近端锚点（兼容 KV 缓存）**：
  - 保持 Zone 1 静态系统前缀逐字节不变以保留提示词前缀缓存命中率，在临近当前用户输入的 Zone 3 自动注入与本轮场景相关的 `<active_continuity_anchor>`（已确认设定约束与最近时间线锚点），缓解长对话中设定被遗忘的问题（支持在设置页一键开关）。
- **分批持久化断点续传、敏感内容三阶隔离与超额分段压缩 + M3 剧情分块记忆**：
  - **增量续压与每批落盘**：对话内「压缩较早对话 / 增量更新」默认从已保存水位线增量续压（另提供「从头重建」），每完成一批完整消息立即落盘分块并推进水位线，中断不丢前序进度，界面实时显示批次进度。
  - **敏感内容隔离降级**：角色扮演/故事模式压缩启用中立客观档案体提示词与细粒度分批；若仍触发内容安全拒绝，自动执行二分拆批隔离 → 辅助模型切换 → 脱敏结构化本地连续性占位摘要（不将原文敏感词注入后续批次，且不把安全拒答计入 API Key 冷却惩罚）；支持「角色扮演/故事自动（默认） / 全部对话 / 关闭」三档与「优先辅助模型压缩」开关。
  - **上下文已超额直接分段压缩**：放开超额状态下的压缩入口限制，优先按安全窗口分批压缩未覆盖历史再重算剩余上下文，避免超额死锁。
  - **M3 长篇剧情分块召回（HypaV3 四桶分配）**：积累 ≥4 段分块时自动将置顶伏笔块与近期连续块放入稳定前文，将与当前输入相关的远期回忆块召回至 Zone 3 并按时序重排；上下文管理面板支持展开查看剧情分块并一键星标置顶伏笔。
- **数据库与备份兼容性**：Room 由 v37 显式升级至 **v38（22 个实体）**，经 `MIGRATION_37_38` 保留全部历史数据并新增 `conversation_summary_chunks` 与 `vector_embeddings` 表（导出 `38.json`）；便携备份同步包含剧情分块与 v38 记忆元数据（派生向量缓存不入备份），并兼容导入旧版 v37 备份快照。
