# Echo 2.8.42

版本 2.8.42/228，Room v37（20 个实体）不变。

## 修复

- 修复 2.8.41 引入的闪烁：键盘已经弹出时，点击输入框会让键盘收起再弹、页面跟着跳动。
- 原因：2.8.41 用“窗口是否收到输入法 Insets”判断键盘状态，命中后清焦点再重建输入会话。但悬浮键盘（分离键盘）和悬浮窗下，应用窗口根本收不到输入法 Insets，判断恒为“键盘已收起”，于是每次点击都清一次焦点——已弹出的键盘被收起又弹回。
- 修复方式：恢复键盘改为无害的幂等动作——只向系统请求显示键盘（`showSoftInput`），不再清除焦点。键盘已弹出时该调用无副作用；键盘被返回键收起后仍能重新弹出。
- 上一版能力保留：输入法收起后点击输入框可重新弹出；长按选词、拖动选区与滚动均不受影响。

## 真机验收

HONOR ROL-W10（MagicOS），USB 调试安装 release 包：

- 全屏（横屏）：键盘已弹出时连续点击输入框，`mInputShown` 全程为 true，键盘不收起、页面不跳动；返回键收起后点击立即恢复。
- 悬浮窗 + 悬浮键盘（窗口收不到 IME Insets 的场景）：键盘已弹出时点击，输入框区域与整窗像素在点击前后完全一致（无焦点丢失、无光标消失）；返回键收起后点击恢复，随后继续输入正常。
- 长按选词仍为系统手柄，键盘不会被误弹。
