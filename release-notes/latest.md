# Echo 2.8.18

修复聊天输入、思考强度选择、时间线 / 设定窗口和 Bot 状态表现。版本 2.8.18/204，Room v37（20 个实体）不变。

- 思考强度按钮缩窄到原智能搜索尺寸，智能搜索恢复自然宽度和文字居中。
- 思考窗口恢复胶囊滑块，档位名称去掉外框，支持拖动和点击选择。
- `Default` 档位仅显示英文名称，仍表示跟随服务端默认强度，不改变实际参数语义。
- 时间线与设定捕捉窗口随内容增高，到达上限后仅内部正文滚动，短内容不再撑满窗口。
- 修复旧值回传可能干扰选区与组合输入的问题，补齐点击空白区域和关闭键盘后再次点击时的输入法唤起。
- 降低拖动选择手柄时的自动滚动速度，使隐藏文字逐步进入视口。
- 主动暂停时 Bot 缓缓闭眼；连接或回复错误时 Bot 摇头并呈现 `><` 眼睛，落定后保留表情，历史消息与减弱动态保持静态。
- Bot 本体与整个思考 / 连接胶囊中心对齐，放大的右上状态符号不再改变本体位置。
- 折叠胶囊按可见文字测量宽度，修复无思考 Token 时尾部空白过大的问题。

Bot 浏览器预览同步动作参数。四套纸本主题仍供预览，未应用到 App，不改变已有主题选择。用户提供的截图只用于定位问题，未复制进仓库或随发布上传。

## 设备验收

本版无数据库迁移。设备安装、启动、输入法、选择手柄、动态布局和真实接口仍须验收，自动测试、浏览器预览及构建成功不能替代这些检查。

1. 用普通与较大字号比较思考 / 搜索按钮，拖动思考滑块并点选首尾档位。
2. 分别查看短候选和长候选，打开键盘，检查自然高度、内部滚动及标题 / 操作可用。
3. 在输入框、修改回复和提示词中进行中文联想、成对标点、光标移动及连续编辑，关闭键盘后再次点击；拖选隐藏长文本并核对滚动速度。
4. 对不同 Bot 样式触发暂停与错误，检查闭眼、摇头和 `><` 表情，再检查历史状态与减弱动态。
5. 对比单行 / 展开、多 / 少文字、有 / 无思考 Token 的胶囊，检查本体居中及尾部留白。
