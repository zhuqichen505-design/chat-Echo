## 设备验收边界

未连接真机或模拟器，自动测试与构建不能替代设备安装启动、触控、输入法、动态视觉与真实接口验收。

1. 各主题浅深模式分别检查“连接 → 回复 → 正常结束”“连接 / 回复 → 主动暂停”“连接 / 回复 → 错误”，观察颜色逐渐变化且符号一致。
2. 暂停后滚动离屏再返回，切换思考气泡 / 头像，重启会话；历史颜色应稳定，避免重新播放旧变色。
3. 在过渡中重试或恢复，观察颜色从当前色继续变化；系统移除动画时直接显示最终状态色。
4. 回复包含英文错误原句以及“回复已停止 / 报错详情”的解释内容时，正常回复保持主色；真实失败仍显示错误色。
5. 反复执行点击输入区、返回收键盘、再次点击、快速连点、发送 / 隐藏输入区，确认键盘响应与输入内容、选区、草稿正常。
