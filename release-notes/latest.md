# Echo 2.8.34

版本 2.8.34/220，Room v37（20 个实体）不变。

## 输入框与输入法

- 修复“键盘收起后再点输入框没反应”：按返回键收起键盘、关闭对话设置弹窗、最近任务小窗悬浮后最大化等场景下，输入框仍处于聚焦状态，但点击不会再唤起键盘。原因是已聚焦字段的原生点击不会再次请求显示键盘，而上一版把这种情形也让给了原生处理。现在只要输入连接仍正常、键盘不在屏幕上，就补一次显示。
- 补显示不会清焦，也不会把正在输入的内容收起再重弹；悬浮输入法的可见性无法从窗口 Insets 读出时同样只补显示、不重建会话。
- 首次点击输入框时先确认原生的聚焦与输入会话真的落地，再在没有显示键盘时补一次；普通点击不会打断上一轮仍在进行的恢复。
- 拖拽手柄等非原生点击入口保持原有行为；不修改对话、消息、API、备份或数据库行为。

## 报错明细

- 多 Key 轮询失败时的“连接异常 · 实时明细”折叠卡片与上方思考 / 状态胶囊统一视觉：16dp 圆角、同款底色与描边、16dp 图标、相同内边距与字体；折叠时宽度随内容收缩，展开明细时占满可用宽度。
- 思考 / 状态胶囊本身的样式未做改动。
