# Echo 2.8.49

版本 2.8.49/235，Room v37（20 个实体）不变。

## 新增与改进

- **时间线与设定总结自动重试**：新增严格结果解析与失败诊断，区分“本轮合法无新内容（`NO_UPDATE`、无变化表述、合法空 JSON / 空数组，保持静默不重试）”与“格式错误 / 残缺 JSON / 安全拒绝 / 空响应或仅推理 / 截断 / 临时服务端异常”；单轮增量提取、过长事件精简、全量与分段梳理、故事设定融入分析统一支持最多 3 次尝试（1 次首试 + 2 次带具体纠错提示的自动重试），并修复可选字段为 `null` 时误判格式错误的问题。取消、本地 HTTP 拦截及 400/401/403/404/413/422 等硬性客户端错误不盲目重试，也不与底层请求重试策略叠加放大。
- **审阅与失败弹窗新增“重新提取”图标按键**：在待确认审阅卡片（含全屏预览模式）、全量时间轴梳理弹窗与故事设定融入弹窗的标题栏统一新增刷新图标按键（`重新提取`）。无论已提取出提案还是多次自动重试后依然失败，均保留原文上下文并可点击重新读取；分段梳理中途失败时续梳失败分块，其余情况清理旧草稿后按原模式重新梳理。

## 修复内容

- **API 配置拖拽中选中项跳变修复**：2.8.48 修正了按下时读取旧下标的问题，但在拖拽过程中实时交换列表仍会改变条目槽位与手柄原点，且位移补偿漏算列表项间距，导致拖拽期间高亮项突然切换。现改为拖拽期间仅做视觉位移与平滑让位、松手后执行一次重排；全程按稳定条目 ID 识别身份，目标位置按中心点与列表项间距计算，拖拽期间忽略数据库回流，并清理旧归位动画任务。同一修复覆盖 API 配置、API Key、模型列表与排队消息四处拖动手柄。

## 兼容性

数据库结构、请求协议、消息格式与备份格式均未改变。
