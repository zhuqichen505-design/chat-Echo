## 操作入口

- 设置 → 界面与外观：删除头像/背景历史，选择六浅色＋六深色色卡；阅读排版、正文字体分别可应用于普通对话。删除只移除历史副本，活动图片保留，重新上传同图可以再次收录。切主题仍恢复对应主题纯色。
- 聊天顶部：开启多方向回复并选择 2–4 个方向，重新打开等待选择的请求。
- 创作：作品 / 人物与世界 / 世界书。故事工作台直接切换写作、人物与世界、会话设定、时间线和世界书；普通对话的模型设置、提取/断点/草稿审核直接共用。本作品人物与世界副本独立于全局资料库。
- 世界书：导入 → 兼容预检 → 保存独立副本 → 启用书目与词条 → 绑定故事。数字表示预算保留顺序，不代表模型指令权限；正则、宏、位置/深度等扩展仍非完整兼容。
- 上下文面板：查看、编辑、重新生成摘要。原文不删除，失败、截断或编辑竞争不推进覆盖位置。时间线同时间只精确去重；旧更新提案不能覆盖人工修改，完整增量超窗口时提示全历史分块梳理。
- 统计：按供应商和模型筛选；查看实报/含估算来源、正式/辅助用途、失败/中断/取消、首段等待与 P50/P95 完成耗时。缓存属于输入、思考属于生成，不重复计数，旧缺失数据不会反推。
