# 当前版本说明

## Echo 2.9.5/240（2026-11-26）

- **提示词前缀缓存全面改造（提升多轮命中率与首字响应速度）**：
  - **Anthropic 三断点滑动缓存**：支持静态 `system` 前缀（BP1）、历史锚点（BP2）与当前稳定用户输入（BP3）自动标记；“回复方向规划”阶段额外启用 BP4 覆盖本轮动态参考块，使规划与正式回复无缝共享 KV 缓存。支持默认 5 分钟与扩展 1 小时缓存时长（设置页「模型连接与错误重试」可按需开关与切换）。
  - **OpenAI / OpenRouter / 兼容网关会话粘性路由**：统一发送 `X-Session-ID` 粘性路由头，并按官方域名/厂商安全白名单附带 `prompt_cache_key`（OpenAI / OpenRouter GPT）、`session_id`（OpenRouter）及 OpenRouter Claude 自动 `cache_control`，避免第三方严格中转报错。
  - **三区前缀稳定性架构与阶梯滞后截断**：取消会话记忆每轮按提问关键词重排，改为按创建时间确定性排序；时间线以确定性时序窗口进入静态前缀，超预算早期节点在当前轮尾注按需召回；关键词世界书、跨会话长期记忆与单轮回复方向指示统一后置至当前用户消息末尾，常规多轮与方向规划前后均保持静态前缀逐字节一致；预算溢出时按 80% 滞后目标一次性腾出追加跑道。
- **角色扮演隔离与配置保存修复**：
  - 新建角色扮演/故事会话自动写入 `roleplay` / `story` 标签，彻底隔离通用助手底设与跨会话偏好；聊天主链路消除角色扮演会话记忆重复注入；角色扮演会话透传隔离标识，防止设备工具误触发；编辑既有 API 配置时完整保留采样、思考、联网、停止词等高级参数。
- **10 项交互、搜索、字体与视觉体验优化**：
  - 对话页右侧搜索同时覆盖提问与回复（含思考内容），支持多词 AND 匹配与上下文摘要直跳；修复右侧提问列表下方空白。
  - API 配置页将「添加API配置」移至顶部、「新对话默认 API」改为独立悬浮下拉菜单不挤压页面、移除卡片设默认星星图标；编辑页将「从 Key 读取模型」移至「默认模型」上方并支持折叠。
  - 首页多选或搜索状态下按系统返回键优先退出当前状态而非直接退出应用。
  - 创作正文字体默认改为跟随手机系统字体，新增 4 款开源中文字体（站酷小薇体、霞鹜文楷等宽、龙藏手写体为 SIL OFL 1.1，霞鹜新晰黑为 IPA 开源字体）连同既有思源宋体覆盖全部 7 款非系统选项，外观设置新增缩微阅读排版实时预览卡；重调 14 款内置纯色背景使浅色粉彩与低明度深色均清晰可辨且保持高对比度。
- **数据库与备份兼容性**：Room v37（20 个实体）、消息存储与备份格式保持兼容。
