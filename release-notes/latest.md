# Echo 2.8.21

版本 2.8.21/207，Room v37（20 个实体）不变，基线 `7e176ee`。

- 修复设定和时间线捕捉窗口被统一布局错误撑高的问题；窗口继续显示在输入框上方，短内容自然收缩，长内容只在正文区域滚动，避免对话文本被抬升和页面上方出现空白。
- 思考强度调整改为输入框上方的紧凑卡片，最大高度 220dp，内部可滚动；移除重复文字说明，保留当前档位和滑杆，标题左侧使用动态思考态 Bot 图标。
- 影响限于对话窗口布局与思考强度窗口展示，不改变请求协议、模型参数语义、消息格式或数据库；Room 仍为 v37 / 20 个实体。

本轮方案为让候选区按内容收缩、在可用高度内滚动，并将思考卡片挂在输入栏同一布局中；新增 6 项真实 Compose/Robolectric 布局回归，覆盖短 / 长内容、小屏、高输入栏、无候选、双候选与卡片定位。
