# Echo 2.8.41

版本 2.8.41/227，Room v37（20 个实体）不变。

## 修复

- 修复输入法收起后，再点输入框无法重新弹出键盘的问题（全屏与悬浮窗均可复现）。
- 原因：Compose 1.6.8 的 `BasicTextField2` 只在“未聚焦”时请求焦点。输入框已聚焦、用户按返回键收起键盘后，点击只负责定位光标，没有任何补弹键盘的路径；此时系统已结束输入会话，`SoftwareKeyboardController.show()` 也不会生效。
- 修复方式：在输入框的 Initial 指针阶段旁路观察点击（不消费事件，原生点击 / 长按 / 拖动全部照常），命中“已聚焦 + 输入法不可见”时结束并重建一次焦点，让输入框重新建立输入会话、键盘随之弹出；长按选词与拖动不算点击，不会误弹。
- 同时移除 2.8.40 调试期遗留在源码里的屏幕红色调试文字（该改动未进入任何已安装的包，但会污染后续构建）。
- 本版包含 2.8.40 的悬浮窗选择手柄修复：非全屏窗口由应用自绘手柄，位置改用「文本布局根坐标 + 光标锚点」，全屏仍用系统手柄。

## 真机验收

HONOR ROL-W10（MagicOS），USB 调试安装 release 包：

- 全屏：首次点击弹出键盘 → 返回键收起 → 再次点击键盘立即恢复；连续点击稳定。
- 光标：收起键盘后点击文字中部再输入，字符插入到点击位置（`ZhMelloXY`），证明重建焦点不会丢失选区。
- 悬浮窗：同样的“收起 → 再点击”路径键盘正常恢复；输入框内光标可见，无游离手柄。
- 长按选词仍为系统手柄，选区正常，键盘不会被误弹。
- 输入框内无调试文字残留，空输入占位与光标显示正常。
