## 启动修复

- 多 Key 管理器在应用启动时编译 HTTP 状态识别正则，原字符类排列会被 Android 使用的 ICU 解析器误读为无效 POSIX 属性。调整等价字符顺序，保留状态识别、失败降权和冷却语义。
- 两路独立原生 ICU 72.1 完整编译均复现旧表达式的 `U_REGEX_PROPERTY_SYNTAX`，修复表达式可编译；旧发布 APK 内也确认存在故障表达式。最终 APK 的 DEX 已确认启动初始化实际加载修复表达式，提取后的完整表达式通过原生 ICU 编译及 12 项分类案例。桌面 JVM 接受原写法，原编译/单测未覆盖这一平台差异。
- 在既有领域测试增加实际三个启动正则的 ICU4J 字符集解析及 HTTP/中文状态格式回归。该回归与原生 ICU 完整编译分别核验，不作为 Android 设备安装启动结果。
- 保留自动时间线精简、多 Key 自定义轮询/冷却、删除上下文保护、备用 Key 恢复和暂停状态等原有功能。
