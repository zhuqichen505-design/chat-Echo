# Echo 2.8.30

版本 2.8.30/216，Room v37（20 个实体）不变。

## 搜索对话

- 搜索框改为同时检索**对话标题与消息内容**，不再需要手动勾选“搜索消息内容”；两类结果分区展示，标题命中的对话不会因为勾选内容搜索而消失。
- 查询词自动去除首尾空白并折叠连续空格，支持多关键词（最多 4 个，按 AND 匹配），“项目 需求”可以命中“项目需求文档”；匹配忽略大小写。
- 结果中的关键词高亮；消息结果按相关度片段展示，片段围绕首个命中截取，不再出现与关键词无关的开头文本。
- 点击消息结果进入对话并**自动滚动定位到该条消息**，同时提示“已定位到搜索命中的消息”；命中未选中的回复变体时会自动切换变体组。
- 搜索期间显示进度而不是“未找到”，避免输入过程中反复闪烁空态；结果超过 200 条时明确提示仅展示最近 200 条。
- 首页搜索标题无命中时自动回退检索消息内容（最多 20 条，同样可点击定位），并提供带当前关键词进入历史记录继续搜索的入口。

## 发送与滚动

- 发送消息后页面会自动贴到底部，覆盖消息落库、等待气泡插入与键盘高度变化的时间差。
- 一旦用户手指拖动列表，自动贴底立即让出，不再抢占阅读位置。

## API 配置

- 点击新建或编辑 API 配置改为进入独立页面，不再是高度受限的弹窗；三个页签（连接 / 密钥 / 模型）占满页面，长模型列表可完整滚动。
- 页面内完成保存：配置本体 → 模型清单 → 头像 → 密钥轮询设置；保存中禁用返回，失败重试沿用已落库 ID，不会重复新增配置。

## 停用配置与模型

- 自动命名、思考链翻译、记忆提炼的模型选择器只列出启用配置与启用模型。
- 上述辅助任务执行时跳过停用配置；指定模型已停用则回退到配置默认模型或首个启用模型，不再调用已停用模型。
- 时间线辅助、翻译、会话配置失效回退、历史导入、首页新建对话、角色 / 场景编辑、工作室导入、智能追加故事均只使用启用配置。

## 输入框与代码整理

- 修复“输入时点击输入框，输入法闪一下”：点击手势开始时同时采样聚焦与输入法可见性，已聚焦且输入法仍在屏幕上时完全不碰焦点、不重复显示键盘。
- 输入法可见性查询由三处重复实现合并为一处；输入框高度不再维护两个可能不同步的状态；移除未被生产路径使用的滚动策略函数。

## 设备与真实接口验收边界

当前无连接设备，未验证安装、启动与以下交互，需人工复验：

- 发送消息后是否稳定贴底；手指上滑拖动时是否立即停止自动贴底。
- 历史记录搜索标题与消息内容、多关键词、高亮、点击定位到具体消息；首页搜索回退到消息内容与跳转历史记录。
- 新建 / 编辑 API 配置页的滚动、键盘避让、保存与返回；保存过程中返回是否被拦截。
- 停用某个 API 配置或模型后，自动命名、翻译等选择器中不再出现该项。
- 打字过程中点击输入框定位光标、连续快速点击、点击拖拽手柄、返回隐藏键盘后再点，应无闪烁且可持续输入。
