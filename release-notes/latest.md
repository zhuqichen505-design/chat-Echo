## Echo 2.9.4/239（2026-11-26）

- **创作阅读页与创作正文字体扩展**：
  - 创作阅读页排版由 3 种扩充至 6 种：保留「沉浸叙事」「纯净直排」「双栏对照」，新增「书页典籍」（首行缩进 + 两端对齐 + 书签双竖线）、「紧凑速览」（高信息密度行距与窄边距）、「剧本分镜」（行动 / 对白横线分镜）。
  - 创作正文字体由 3 种扩充至 8 种：保留「内置思源」「现代无衬线」「打字机等宽」，新增「跟随系统」「经典宋体」「精印书宋」「轻盈细黑」「随笔手写」。
  - 外观设置「创作阅读页」与「创作正文字体」新增实时排版与字体预览卡，聊天正文、Markdown 段落与用户消息样式随所选模式自动联动。
- **UI 与主题设计规范文档**：
  - 仓库新增 `UI_THEME_DESIGN_SPEC.md`，整理 15 套主题十一维架构、设计令牌、双模式对比度 ≥ 4.5:1 检查项、共享组件规则与后续自动更新流程。
- **API 配置界面、列表选择与 Key 拖拽排序优化**：
  - API 配置管理卡片移除 `OPENAI` 等接口类型文字字样，信息展示更清爽。
  - 顶部「新对话默认 API」改为默认收起的下拉列表（默认仅显示当前默认 API，点击展开所有已配置 API 供选择；选中未启用配置时弹窗二次确认「设为默认并启用」）。
  - 编辑 API 配置页顶部新增常驻四分区快跳栏（`连接` / `密钥` / `模型` / `其他`）并随滚动自动高亮当前段落；优化页面信息逻辑，将「模型对话头像」与「多 Key 轮询策略」移入底部「其他」分区，默认与已配置模型合并前置、接口拉取列表置后；Key 列表条目去除 `(停用)` 后缀、调整顺序按钮改为左右横排。
  - 修复 API Key 等可拖拽列表在拖动切换顺序时非选中卡片联动放大/投影及松手回弹跳动的问题，修正不等高条目偏移公式并补偿手柄缩放位移，提升跟手与换位稳定性。
- **数据库与协议兼容性**：Room v37（20 个实体）、请求协议、消息格式与备份格式均无变化。
