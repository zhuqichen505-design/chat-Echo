本版将摘要拒绝保护与“直接截断（暴力压缩）”构建为可安装的 Echo 2.8.13。摘要模型返回安全限制、只有 Markdown 标题或空占位结构时，不再被保存为成功摘要；直接截断档可以在不依赖摘要模型的情况下按比例减少发送的早期对话。

## 上下文压缩修复

- 独立 refusal 字段、结构化拒绝块、流式拒绝片段和结束原因统一检查。模型拒绝不会推进摘要覆盖位置、替换旧摘要或计为成功；已误存的拒绝/纯标题摘要不会替代原始对话，需要时从原文重建。
- 新增“直接截断（暴力压缩）”档，比例为 10%～90%，步长 5%。按完整对话轮次向下取整截去最早轮次，保留置顶轮次和最近至少一轮。
- 直接截断档不调用摘要模型、不发送历史摘要，只影响后续请求的上下文范围；本机聊天记录不删除。调低比例或切回其他档位后可以重新读取原文。
- 所选比例下仍超预算时提示提高截断比例、减少置顶内容或缩短输入，不自动扩大截断范围。独立记忆、时间线和世界书保持原设置，仍可能提供背景并占用预算；分支会话继承压缩档位和比例。
