# Echo 2.8.16

修复聊天捕捉面板、暂停错误保留、分支创建及参考资料交互。版本 2.8.16/202，数据库保持 v37。

- 捕捉到的设定、时间线和提取失败提示共用限高滚动区域，长内容可滑动查看；输入栏优先保留空间，标题为关闭按钮留位。
- 每次提取使用独立候选 ID，修复连续相同的总结失败或候选内容经状态合并后点击 × 无法关闭；旧窗口回调不会误关下一条候选。
- 主动暂停前尚未恢复的连接错误与已生成正文、思考一同保存，可展开查看和复制；已恢复错误继续清除，诊断内容不会进入后续模型上下文。
- 创建分支立即显示进度并阻止并发重复创建；隐藏输入关联改为一次消息快照重映射，避免长历史逐条重读。分支仍保留消息版本、设置及有效注入关联。
- 修复数字链接、脚注和分组引用的点击及网址解析，支持编号资料、Markdown 链接、裸网址与本轮搜索来源回退；缺失真实网址时明确提示。链接详情使用纵向操作区，避免“打开网页”按钮受长网址挤压反复换行。

## 升级与设备验收

Room v37（20 个实体）不变；同 applicationId、同签名及更高 versionCode 满足保留数据覆盖升级条件，无需卸载或清除应用数据。未连接真机或模拟器，安装、启动、键盘/触控、动态布局与用户真实接口仍须设备验收。多次独立搜索对同一局部编号给出不同网址时，正文明确网址优先；没有明确映射的歧义或缺失来源不猜链接。

1. 覆盖安装后打开原对话，触发长设定与时间线，弹出键盘并滚动全文，确认输入、发送和关闭可用。
2. 连续触发相同的总结失败，逐条点击 ×；确认无需返回主页即可关闭，旧回调不会关闭下一项。
3. 连接失败或重试提示出现时主动暂停，重进对话，确认错误详情、正文和思考保留；恢复输出后再暂停不保留已恢复错误。

5. 点击正文数字/分组引用及末尾来源，核对实际网址；用长网址和较大字体检查详情操作按钮，缺失网址应明确提示。
