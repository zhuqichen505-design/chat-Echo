# Echo 2.8.48

版本 2.8.48/234，Room v37（20 个实体）不变。

## 修复内容

API 配置页按住左上角六点手柄排序时，偶尔会拖动到别的配置。原因是列表重排后界面下标会变化，而手势仍使用重排前的下标；现在按住手柄时会按配置自身 ID 重新定位当前位置，拖拽始终作用于按住的那一张卡片。同一修复也覆盖 API Key、模型列表与排队消息的拖动手柄。

## 新增设置

“模型连接超时”可在 设置 →“模型失败与重试”中调整，默认 120 秒，可设为 30–600 秒。该时间用于等待模型返回首个正文或思考内容；超时后按既有的错误重试策略处理，对之后发出的请求生效。

## 兼容性

数据库结构、请求协议、消息格式与备份格式均未改变。
