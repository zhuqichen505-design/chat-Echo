## 修复与使用

- **失败后原参数重试**：自定义比例或档位已经保存，摘要失败后仍可点击“按当前比例重新压缩”或“重试压缩”，无需先修改比例。
- **短请求与真实错误**：摘要连接 10 秒、读写各 30 秒、单次 HTTP 调用 45 秒；不可达和超时不叠加通用重试或备用 Key 轮询。长历史由多个请求组成，全部整理可以超过 45 秒。
- **判空网关兼容**：仅 OpenAI 兼容接口的 HTTP 500/502 且结构化错误明确包含 `empty response detected` 时尝试一次流式摘要；成功才按实际 Key 记住能力，失败保留两次原因。该错误不直接等同于上下文超限。
- **完整输入与摘要校验**：分段预算包含模板、旧摘要、来源包装和输出空间，中文/Emoji/单条长消息保持全源保序覆盖。只有明确容量错误才缩小失败分块；合法纯正文可保存，空、仅思考、拒绝或截断正文不保存，全部成功才推进覆盖水线。
- **摘要故障后继续对话**：预算内使用有效旧摘要和全部未覆盖原文继续正常发送，同一配置不反复触发失败摘要；超预算明确提示重试或更换可用模型。手动重试始终可以再次请求，失败不丢原文。
- **凝练事件与时间线**：保留独立事件、必要因果、选择、转折、结果、约束和未决线索；合并小动作，省略无后续作用的景物、感官、神态和重复心理。详略取决于事实与影响，不跟随描写篇幅扩写；全量和增量时间线同步生效。

入口为聊天页上下文用量面板；普通与创作会话共用。压缩失败后可保留当前策略重试，必要时先检查错误原因或切换可用模型。时间线仍可先审阅提取草稿后保存。
