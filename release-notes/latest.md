# Echo 2.9.1

版本 2.9.1/236，Room v37（20 个实体）不变。

## 新增与改进

- **三套全新细节工艺主题（青瓷 / 蓝图 / 漆匣）**：在设置 →「外观与显示」→「主题预设」中新增三套注重材质、边框工艺与排版节奏的主题，全部提供浅深双模式且全对文本对比度 ≥ 4.5:1（WCAG AA）：
  - **青瓷（CELADON）**：雨过天青浅釉 / 夜窑影青暗釉配色，搭配瓷釉微矿粒、宋瓷冰裂开片底纹、顶缘釉光高光与内缩双唇边、`20dp` 温润圆角、不对称瓷釉用户气泡及衬线标题 × `27sp` 舒朗行高。
  - **蓝图（BLUEPRINT）**：硫酸纸制图版 / 经典氰版蓝图配色，搭配 16/80dp 制图坐标网格、主交叉点十字准星与左缘精密标尺刻度、四角 L 形注册角标、`2dp` 锐角轮廓、用户气泡左侧高亮索引竖条及全链路等宽技术标头与标签。
  - **漆匣（LACQUER）**：朱砂宣金暖卷 / 黑漆描金夜匣配色，搭配丝缎横刷漆纹、左右双线描金页框、卡片内缩 `3dp` 描金双框与四角细金点、`10dp` 典雅匣盒与气泡右侧印章竖线及 `1.2em` 典籍首行缩进排版。
- **时间线与设定待确认窗口内部排版优化**：严格保持待确认窗口的既有位置与大小上限（锚定输入栏上方、最大 `440dp`），重构内部信息层次——推进时空采用紧凑徽章条；时间线事件独立轻卡片并拆分为操作 / 时间 / 带色点分类胶囊与原记录对比块；提取设定新增分节标题与实时选中计数，每条设定自成可点击轻卡片并将「原设定 / 依据 / 说明」收拢在同一张卡片内部的细分隔线之下，避免多条设定说明错位。
- **应用设定成功与失败提示迁至页面上方**：将确认时间线/设定、保存设定记忆、全量时间轴保存与故事设定融合的成功（绿色）及失败（红色）提示统一迁至对话页面顶部横幅展示，不再在底部弹出；若全量时间轴或故事设定弹窗因保存失败而保持打开，同步在弹窗内容最上方展示失败提示条。

## 修复内容

- **修复 120s 慢响应提示被误显示为“连接重试中”**：在自定义较大连接超时（如 300s）时，原先第 120 秒弹出的慢响应安抚提示复用了重连状态字段，导致状态机将其误判为重连态并重置等待计时器，在约 150 秒时误显“连接重试中，已等待 30s…”。现慢响应提示保持正常等待态（`Connecting`）且不重置等待计时，继续平滑递增直至收到回复或达到自定义超时；首字/思考到达或真实触发重连时自动取消慢响应定时任务。

## 兼容性
